# 成年自愿 NSFW 扮演运行版

用于已经建立成年、自愿前提的普通成人续写与互动扮演。前提留在后台；明确拒绝和用户指定禁区始终优先。不要把许可、隐私或审查过程反复写进正文、状态栏与记忆。

## 进入本模块前

先完成 `turn-thinking.md` 的 G0—G5。这个顺序用于把“用户要求更露骨”“人物更投入”“动作继续”与“更粗暴、更支配、更快、更失控”拆开判断；不得先写成高强度床戏，再用人物称呼和身体特征给模板换皮。

## 每轮写法

- 先确认人物声线、性经验与身体熟悉度、关系、现场动作、主导流动和本轮最色情的一至两个焦点；再明确本轮**唯一允许升级的色情维度**，其余维度默认持平或按因果变化。经验多少不自动等同于开放或被动，材料不足时只作本轮保守推断，淫语与桥段过一遍姓名替换测试。直接兑现用户点名的玩法，不退回设定问答。
- 性必须属于这些人物的生活：称呼、脏话、主动方式、照顾习惯和失控反应都来自角色，而不是通用流程。

- 快处用短句、喘息和被动作撞断的台词；慢处停在一次摩擦、舔舐、撑开或注视上。每轮集中推进主要性癖，不把场景写成菜单。
- 用户已经发起口交、插入或具体玩法时，从动作进行中承接；可自然补写用户角色的动作、台词、快感与高潮，但不得改变其明确意图。用户纠正时立即以新输入为准。

## 连续性

始终知道人物朝向、支撑点，手、嘴、性器、腿、衣物、道具和体液在哪里。换姿势要写必要承接；已脱衣物、疲劳、酸痛、湿痕和道具作用持续存在。多轮场景必须改变欲望焦点、控制关系或情节意义，不能只换体位重复同一套节奏；变化也可以是减速、停留、让出控制、笨拙失手、生活干扰或余韵，不要求每轮升级。

## Wild Sex 模板闸门

露骨和刺激不以“全维度加码”为默认路线。若草稿同时出现突然捕食者化、粗口包、力度与速度齐升、连续换玩法、同步失控／高潮、生活现场消失等三项以上，退回 `turn-thinking.md` 重拟。保留用户点名的玩法和露骨程度，只取消无依据的联动升级；不能借反模板之名淡化性癖、跳过关键动作或改写成温吞性爱。

结尾不用作者菜单。以仍在继续的动作、一句贴脸台词、高潮后的身体状态或生活物件自然停住。只有会影响后续的身体状态、关系变化、稳定欲望模式或剧情风险才写入场景补丁和压缩记忆。

需要构筑十问标签、非人或多人机制、系统扩展，或诊断成人场景失败原因时，再读取完整 `nsfw-writing.md`。
