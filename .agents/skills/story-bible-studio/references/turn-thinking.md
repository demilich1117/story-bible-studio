# 写前停顿与抗漂移关卡

普通轮只需轻量检查用户意图、人物一致性和自然停点。出现用户纠正、明显漂移或复杂转场时，按需使用下列诊断项或完整决策卡；不要求每轮填表。诊断只用必要短语，不输出、不落盘、不塞进状态栏或记忆。材料不足时标作“未知／本轮不建立”，不能为填格补造证据。

与 `nsfw-runtime.md` 互补：本模块先决定人物为什么会这样行动、哪些维度不得随惯性升级；成人模块随后决定如何把已经选定的色情焦点写具体。成人轮必须先过本模块，再过成人模块，不能倒序。

## 按需使用的诊断项

以下 G0—G5 是处理具体问题的诊断项，可合并或跳过不适用项；仅复杂问题需要完整检查。诊断应指向实际依据，不为完成流程凑答案。

优先使用已加载的当前上下文。用户纠正、复杂转场或明显重复使人物基线不清时，从当前任务允许的固定 Profile、压缩记忆或场景材料中补读缺失依据；不因普通转场或材料已加载而重复读取。不得拿最近几轮的高频表现代替稳定基线。

### G0 当前回合契约

只看用户最新输入，先分清三件事：

- **必须兑现**：用户本轮明确发起、要求、纠正或拒绝了什么？
- **允许补写**：以本包有效 agency 为边界：user-driven 不代写 user 决定性言行与内心；short-rp 不新增 user 动作、对白、内心或决定，只承接用户明确写出的行为及外部结果。人称与主动性不扩大权限。
- **不得偷加**：用户没要求、档案没建立、却最容易被类型模板自动补出的是什么？

用户点名提高一个维度，不等于授权其他维度一起提高。例如“写得更露骨”不自动等于更粗暴、更羞辱、更失控；“继续”只表示承接，不表示强度继续上升。

### G1 基线—变化—反证

为每个本轮关键人物各给出三个不同答案：

1. **稳定基线**：跨场景仍成立的选择机制或声线核心。
2. **本轮变化**：由最新输入或刚发生事件造成的唯一局部变化。
3. **反向证据**：档案或前文中能阻止把该变化夸大成人格重写的一条证据。

最近三轮是现场证据，不是趋势线。一次沉默、粗口、妒意、高潮、服从、支配或失控不能自动升格为稳定人格；连续出现也先检查是否只是同一场景尚未结束。人物可以变化，但变化必须有事件、选择和后果，不靠模型自行线性外推。

### G2 本轮因果骨架

用短语补齐一条可见因果链：

`当下欲求 → 人物惯用策略 → 现场阻力／代价 → 本轮具体动作 → 立刻改变了什么`

常规模式至少一个动作须符合人物能力、关系位置和物理现场。短 RP 允许只回应、观察或等待，因果链可止于尚未回应，不强迫改变局势或添加动作。若换成同类型角色仍成立，重选人物自己的策略。没有因果变化不靠更大的情绪词、动作或感官堆叠伪装推进。

### G3 强度向量解耦

分别判断本轮相对上一轮的变化，只写 `降／持平／升`：

- 情绪外显
- 权力压迫
- 动作力度
- 节奏速度
- 语言粗度
- 性描写露骨度（非成人场景记为“不适用”）
- 关系后果

每个“升”都要能指向用户要求或场内因果；没有依据就改成持平或降。禁止把“更投入／更色情／更危险／更亲密”误当成七项一起单调上升。停顿、笨拙、幽默、照顾、精确服务、克制和生活干扰都可以比加码更有张力。

### G4 惯性路线反选

先用一句短语指出“如果直接顺着类型惯性写，下一拍会是什么”；再故意不选它，除非用户明确要求或 G0—G3 已给出人物化因果。

重点排查：突然威压或占有宣告、无依据的哭诉或训话、统一粗口／淫语包、重复口头禅、换姿势代替推进、每轮都更快更狠、所有人同步失控、高潮即自动收束。反选不是机械写相反动作，而是回到 G2，选择更属于当前人物的下一拍。

### G5 空间与落点

确认人物朝向、距离、支撑点，手、嘴、衣物、物品、道具与伤势在哪里；按有效 span 决定跨度，inherit 沿用一个主推进和至多一个副变化。短 RP 默认单拍，允许无新增变化；在需 user 回应前自然停笔，不强制问句。提前决定自然停点，不为写满一轮继续升级。

## 私有回合决策卡

复杂问题可用以下八格辅助检查；只填写相关项，每格一个短语，不写长篇推理：

```text
用户契约：
场景新增：
人物基线：
反向证据：
因果下一拍：
允许上升项：
拒绝的惯性路线：
物理落点／停点：
```

不适用项可省略，缺少证据记为未知，不阻塞与其无关的起草。用户纠正、漂移或复杂转场时只复核相关项；只有缺失依据确实影响后续写作时才补读材料。

## 成人场景的 Wild Sex 模板闸门

粗暴、支配、羞辱、快速、多人或强烈失控本身都不是问题；问题是模型把它们捆成一个默认套餐。出现下列三项及以上而缺少用户要求或人物化因果时，判定正在滑入 **Wild Sex 模板**，整段不得直接输出：

- 人物突然变成捕食者、所有者或命令者；
- 露骨度一升，动作力度、语言粗度和权力压迫同步上升；
- 用“彻底、疯狂、野兽、碾碎理智”等概括词代替具体反应；
- 淫语退化为“求我／骚货／夹紧／别停”等可换名套件；
- 一轮塞入多种玩法或多次换位，把数量当满足度；
- 以更快、更深、更狠作为唯一升温方法；
- 双方同时失控、同时高潮，并在高潮后自动温柔收束；
- 场景中的职责、幽默、熟悉习惯、笨拙、物件和现实后果全部消失。

触发后执行一次重拟：保留用户点名的性行为和露骨程度，只把**没有依据的联动升级**降回去；重新选择一个人物化欲望焦点、一个具体动作反馈和一个生活／关系后果。不要因此淡化、黑屏或转成边界教育。

## 草稿后的冷复核

初稿完成后与最近已选原文分开看一遍，只问四个问题：

1. 哪一句最像“这类角色都会说的话”？改成人物自己的策略或删掉。
2. 哪个特征只是因为近几轮常见而又被重复？冷却它。
3. 哪个强度维度没有依据却被带着一起升级？单独回调。
4. 结尾是否为了制造钩子或满足成人模板而强行威胁、失控、高潮或收束？改到 G5 选定的自然停点。

同时将草稿与本次有效文风规则对照，检查语域漂移、旁白侵入对白、人物口气趋同、机械重复及修辞过量。场景变化可改变节奏；人物已建立的特殊表达、仪式与引用保留在局部，不能扩散为全篇基线。不凭禁词数量、句长或对白比例判定合格。

复核只改命中的局部，不把正文改成规训感、保守化或刻意反高潮。文风检查合并在本次冷复核中，不增加独立串行关卡，不另写或保存分析卡。

## 事后路径

- 用户报告 OOC：`variant add` 重写；先指出错误发生在基线、变化、强度还是惯性路线，不用一次投诉重写整个人格。
- 正文与会话不得反向产出声线结论。OOC 只能触发 Story Bible 显式修订请求；修订时回到既有人设重新推演或由用户确认，单场异常只修当前场景或变体。
- 某特征反复被放大：档案禁偏行增加一条带正向替代的反模板；高频复发桥段可并入回环梗冷却台账。
- 压缩记忆只记事实、选择和后果，不把最近文风、频率或烈度压缩成稳定性格。
